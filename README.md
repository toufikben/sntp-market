# SNTP · سوق سانتيبي

تطبيق أندرويد يجيب على سؤال واحد: **هل سوق سانتيبي (الحميز) مفتوح الآن؟**

سوق الجملة لا ينشر جدولاً، وتوقيته يتغيّر بقرار إداري أو بوصول شحنة أو بموسم. النتيجة أن تاجر
التجزئة القادم من ولاية أخرى يحمّل شاحنته ويسافر مئات الكيلومترات على الاحتمال. هذا التطبيق
يستبدل الاحتمال بمعلومة، ويقول صراحةً حين لا يعرف.

---

## المبدأ الحاكم

**لا يكذب التطبيق أبداً.**

كل قيمة تُعرض تحمل معها مصدرها وحداثتها. لا تُعرض معلومة قديمة كأنها حاليّة، ولا تُخترع حالة
حين لا يوجد تصويت. الحالات الأربع الممكنة:

| الحالة | متى |
|---|---|
| مفتوح / مغلق | إجماع تجار موثوق، أو قرار إدارة السوق |
| غير مؤكد | تعارض التصويتات أو عدد المصوّتين أقل من 3 |
| لا بيانات اليوم | لا تصويت ولا جدول — مع زر اتصال بتاجر موثّق |

```
  util/         MarketTime (Africa/Algiers) · Geo (أوزان التصويت)

```

### قاعدة القراءة

```
فتح التطبيق
   ├── الشبكة متاحة → GET market_state  → Freshness.LIVE   (ويُحفظ محلياً)
   └── الشبكة فاشلة → آخر حالة محفوظة
         ├── أقل من 20 دقيقة → Freshness.CACHED
         ├── أقدم → Freshness.STALE  + لافتة تحذير
         └── لا شيء → Freshness.OFFLINE + الجدول المعتاد
```

### محرّك الإجماع

وزن كل تصويت = **القرب × السمعة × الحداثة**

| العامل | القيمة |
|---|---|
| داخل 1.2 كم | 1.0 |
| حتى 5 كم | 0.35 |
| أبعد | 0.0 (يُحفظ للتشخيص، لا يُحتسب) |
| سمعة ≥ 180 | 1.8 |
| سمعة عادية 100 | 1.0 |
| سمعة مشكوك فيها | 0.4 |
| أحدث من 45 دقيقة | 1.0 |
| أقدم من 3 ساعات | 0.0 |

**النشر:** الفائز يحتاج ≥ 60% من الوزن **و** ≥ 3 أجهزة مختلفة. أقل من ذلك = «غير مؤكد».
**تجاوز الإدارة** يتقدّم على كل شيء، ويُعلَن كمصدره.

**الدفاعات ضد التلاعب:** GPS إلزامي داخل النطاق · تصويت واحد لكل جهاز · حد 20 دقيقة بين
تصويتين · Play Integrity (M2) · سمعة تنخفض عند مخالفة الإجماع اللاحق.

### التصويت بلا إنترنت

الشبكة داخل الحميز ميتة عملياً. التصويت يُكتب في ملف محلي ويُرسل عند أول اتصال. السيرفر يرفض
أي تصويت أقدم من 3 ساعات، فلا يلوّث طابور قديم حالة اليوم.

## البناء

### محلياً
```bash
echo "SUPABASE_URL=https://xxxx.supabase.co" > secrets.properties
echo "SUPABASE_ANON_KEY=eyJ..." >> secrets.properties
./gradlew assembleDebug
```

### عبر GitHub Actions (الطريق المعتمد)
كل push إلى `main` يبني APK ويرفعه كـ artifact. لا حاجة لأي أداة محلية.

أضف في Settings → Secrets → Actions:
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

بدونهما يُبنى التطبيق ويعمل من البيانات المحلية مع لافتة «غير مؤكد» — وهو سلوك مقصود.

## قاعدة البيانات

`supabase/schema.sql` جاهز للتشغيل في **مشروع Supabase جديد خاص بهذا التطبيق**.
يُنشئ: `markets` · `market_schedule` · `shops` · `devices` · `reports` · `market_state` ·
`market_override` · `state_history` · `products` · `purchases` · `entitlements` ·
`promo_grants` · `billing_events` · `sponsors` · `admin_actions`
+ محرّك الإجماع + RLS + مهام pg_cron (إعادة حساب كل 5 دقائق، لقطة يومية، تنظيف 30 يوماً).

## الخطط

| الخطة | السعر | المحتوى |
|---|---|---|
| مجاني | 0 | حالة اليوم · الجدول · السجل · 3 مواضع إعلان |
| Pro | 1000 دج/شهر · 9000 دج/سنة | بلا إعلانات · إشعارات · أرقام المحلات · 3 أسواق |
| Boutique | 2500 دج/شهر | صفحة موثّقة · «مفتوح الآن» · كتالوج مصغّر |

الدفع عبر **Google Play Billing**، والتحقق سيرفرياً عبر RTDN. «Pro مجاني لأول 500 مستخدم»
يُنفَّذ بطبقة `entitlements` موحّدة (مصدر `promo`)، لا بعرض داخل Play.
