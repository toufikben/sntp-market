SNTP · سوق سانتيبي

هل السوق مفتوح الآن؟ إجابة يجمعها التجار، لا إدارة السوق.

  • حالة واحدة واضحة: مفتوح / مغلق / غير مؤكد / لا بيانات.
  • ساعة الفتح أو الإغلاق، والسبب، وعدد المؤكدين.
  • الجدول الأسبوعي المعتاد وسجل الشهر.
  • دليل محلات السوق مع أرقامها.
  • يعمل بلا إنترنت مع وسم صريح «آخر معلومة معروفة».
